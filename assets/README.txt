Ce dossier est vide intentionnellement.

Neon Survivors ne nécessite aucun fichier image, police ou son
externe : tous les visuels sont dessinés en Canvas 2D (formes,
dégradés, particules) et tous les sons sont générés en direct
avec la Web Audio API (voir js/audio.js).

Ce dossier est conservé pour respecter l'arborescence du projet
et pour accueillir facilement de futurs assets si vous décidez
d'en ajouter (sprites, musiques, etc.).
